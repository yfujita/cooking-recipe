# カツオのネバネバ丼

カツオの漬け、長芋、納豆オクラの3種類をたっぷり乗せたネバネバ丼。

## 材料

### カツオの漬け

* カツオのたたき
* みりん
* 酒
* 醤油
* すりごま
* すりおろし生姜

### 長芋

* 長芋

### ネバネバ納豆

* 納豆
* オクラ
* ネギ
* 亜麻仁油
* 醤油
* 味噌
* かつお節

### その他

* ご飯

---

## 作り方

### 1. カツオを漬ける

1. みりんと酒を合わせ、電子レンジで**1分30秒ほど加熱**してアルコールを飛ばす。
2. 粗熱が取れるまで冷ます。
3. **みりん＋酒の合計量の約1.5倍の醤油**を加える。
4. すりごまとすりおろし生姜を加えて混ぜ、漬けダレを作る。
5. カツオを漬けダレに入れ、**10分ほど漬ける**。

### 2. 長芋を準備する

長芋の皮をむき、千切りにする。

### 3. ネバネバ納豆を作る

ボウルに以下を入れ、よく混ぜ合わせる。

* 納豆
* オクラ
* ネギ
* 亜麻仁油
* 醤油
* 味噌
* かつお節

### 4. 盛り付ける

丼にご飯を盛り、

* カツオの漬け
* 長芋の千切り
* ネバネバ納豆

の3種類を乗せたら完成。大葉を乗せてもOK。
